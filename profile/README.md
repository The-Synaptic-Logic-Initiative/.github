# The Synaptic Logic Initiative [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
**An Independent Research & Computational Neuroscience Portfolio**

Welcome to **The Synaptic Logic Initiative**. This repository serves as a centralized hub for 19 independent computational models, literature syntheses, and bio-inspired AI architectures. The initiative bridges the gap between biological neural mechanisms and artificial neural network constraints, exploring how complex cognitive phenomena emerge from network topology.

---

## 🧠 Research Pillars & Project Directory

Our work is systematically categorized into three core areas of inquiry. Explore the documentation and source code for all 19 implementations below:

### 🔬 Pillar A: Canonical Brain Circuits & Biophysics
*Focus: Modeling exact biological and mechanistic properties of the brain.*

| Project | Core Biological Concept | Architecture / Model Approach |
| :--- | :--- | :--- |
| **Working Memory Capacity Limits** | Resource allocation & limits in the PFC | Recurrent Neural Network (RNN) simulation |
| **Attentional Selection** | Gating via inhibitory interneurons | Inhibitory feedback loop mechanism |
| **Sensory Adaptation & Habituation** | Synaptic depression & stimulus filtering | Dynamic synaptic weight decay model |
| **Pattern Completion** | Auto-associative retrieval in CA3 | Hopfield Network / Associative Memory |
| **Fear Conditioning Circuit** | Amygdala plasticity & threat pairing | Hebbian learning with error-correction |
| **Model of Forgetting Curves** | Synaptic decay over time matrices | Mathematical decay & consolidation functions |

### 🤖 Pillar B: Bio-Inspired AI & Comparative Architectures
*Focus: Benchmarking biological neural systems against modern machine learning frameworks.*

| Project | Core Inquiry | Frameworks Compared |
| :--- | :--- | :--- |
| **Cross-Model Comparison** | Temporal data processing efficiency | Spiking Neural Networks (SNN) vs. LSTM |
| **Information-Theoretic Analysis** | Entropy and information routing efficiency | SNN vs. Vanilla RNN |
| **Biological vs. Artificial Attention** | Top-down biological gating vs. Scaled Dot-Product | Mathematical & functional comparison matrix |
| **Predictive Coding Network** | Error-driven hierarchical processing | Rao-Ballard Predictive Coding Framework |
| **Transfer Learning** | Plasticity-driven generalization in bio-networks | Custom Synaptic Scaling Algorithm |
| **Noise Injection & Robustness** | Stochasticity in biological vs. artificial layers | Gaussian Noise vs. Synaptic Pruning |
| **Neural Scaling Laws** | Efficiency metrics across scale expansion | Biological scaling dynamics vs. LLM scaling |

### 🌐 Pillar C: Emergent Cognition & Multi-Agent Systems
*Focus: How complex behavioral traits, biases, and choices spontaneously emerge from network dynamics.*

| Project | Behavioral / Cognitive Phenomenon | Target Architecture |
| :--- | :--- | :--- |
| **Confirmation Bias** | Feedback loops freezing network weights | Recurrent network under biased input streams |
| **Cognitive Bias in Transformers** | Attention-weight capturing human-like heuristic bias | Transformer Layer Attention-Map analysis |
| **Decision-Making Under Uncertainty**| Drift-diffusion integration thresholds | Drift-Diffusion Model (DDM) simulation |
| **Multi-Agent Cognitive Network** | Collective intelligence & communication boundaries | Multi-Agent Reinforcement Learning (MARL) |
| **Astrocyte-Inspired Modulation** | Non-neuronal tripartite synaptic modulation | Custom Glial-inspired network layer extension |
| **Unified Model** | Integration of Memory, Attention, and Decision | Unified system pipeline architecture |
